# 通信层模块文档

**文件**: `Software/communication.py`

## 1. 模块职责

接收下位机20通道扫描FFT数据，解析单帧协议，管理TCP连接。

---

## 2. 核心类：Communication

### 2.1 初始化

```python
def __init__(self, state, fft_data_queue):
    """
    Args:
        state: 系统状态对象
        fft_data_queue: 与DataProcessor共享的队列
    """
    self.socket = None
    self.state = state
    self.fft_data_queue = fft_data_queue
    
    # 扫描参数
    self.channel_count = 20
    self.fft_length = state.fft_length  # 单通道FFT点数(512)
    self.total_fft_length = 10240       # 20×512
    self.bytes_per_sample = 4           # float32
    
    # 协议
    self.PACKET_MAGIC = 0xAABBCCDD
```

### 2.2 数据协议

**单帧格式**：
```
[魔数 4B][帧ID 4B][数据长度 4B][FFT数据 N×4B]
- 魔数: 0xAABBCCDD (用于同步)
- 帧ID: uint32 (帧计数)
- 数据长度: uint32 (字节数)
- FFT数据: 10240个float32 (20通道×512点)
```

## 3. 核心方法

### 3.1 连接管理

#### connect(ip, port)
```python
def connect(self, ip, port):
    """建立TCP连接并启动接收线程"""
    self.socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    self.socket.connect((ip, port))
    self.socket.setsockopt(socket.SOL_SOCKET, SO_RCVBUF, 1MB)
    
    # 启动接收线程
    self.receive_thread = threading.Thread(target=self._receive_loop, daemon=True)
    self.receive_thread.start()
    self.state.communication_thread = True  # 触发信号
```

#### disconnect()
```python
def disconnect(self):
    """关闭连接"""
    self.state.communication_thread = False
    self.socket.close()
```

### 3.2 命令发送

#### send_command(command_name, value)
```python
def send_command(self, command_name, value):
    """发送控制命令到下位机
    
    Args:
        command_name: 命令名称 (如"SET_FFT_LENGTH")
        value: 参数值 (uint32)
    
    协议格式: [code 1B][value 4B]
    """
    cmd_info = self.command_protocol["commands"][command_name]
    code = int(cmd_info["code"], 16)
    packet = struct.pack(">BI", code, value)
    self.socket.sendall(packet)
```

**支持的命令**（从`command.json`加载）：
- `SET_FFT_LENGTH`: 设置FFT长度
- `SET_SAMPLE_RATE`: 设置采样率
- `START_SCAN`: 开始扫描
- `STOP_SCAN`: 停止扫描

### 3.3 数据接收（核心）

#### _receive_loop()
```python
def _receive_loop(self):
    """接收线程主循环"""
    while self.state.communication_thread:
        try:
            # 1. 接收帧头(12字节)
            header = self._recv_exact(12)
            magic, frame_id, data_length = struct.unpack(">III", header)
            
            # 2. 验证魔数
            if magic != self.PACKET_MAGIC:
                self._fast_sync()  # 重新同步
                continue
            
            # 3. 接收完整帧数据
            frame_data = self._recv_exact(data_length)
            fft_data = np.frombuffer(frame_data, dtype=np.float32)
            
            # 4. 更新统计
            self.state.sent_frames = frame_id
            self.state.received_frames += 1
            
            # 5. 放入队列
            self.fft_data_queue.put_nowait({
                "timestamp": time.time(),
                "data": fft_data,
                "length": len(fft_data),
                "frame_id": frame_id
            })
            
        except queue.Full:
            # 队列满，丢弃最旧数据
            self.fft_data_queue.get_nowait()
            self.fft_data_queue.put_nowait(frame_data)
```

#### _recv_exact(num_bytes)
```python
def _recv_exact(self, num_bytes):
    """精确接收指定字节数（阻塞直到收齐）"""
    data = bytearray()
    while len(data) < num_bytes:
        packet = self.socket.recv(num_bytes - len(data))
        if not packet:
            return None  # 连接断开
        data.extend(packet)
    return bytes(data)
```

#### _fast_sync()
```python
def _fast_sync(self):
    """魔数丢失时重新同步"""
    magic_bytes = struct.pack(">I", self.PACKET_MAGIC)
    buffer = bytearray()
    
    for _ in range(100000):  # 最多搜索100KB
        byte = self.socket.recv(1)
        buffer.append(byte[0])
        if len(buffer) > 4:
            buffer.pop(0)
        
        if bytes(buffer) == magic_bytes:
            return True  # 找到魔数
    
    return False  # 同步失败
```

## 4. 数据流

```
下位机
  ↓ TCP流
Socket.recv()
  ↓ 字节流
_recv_exact(12)  → [魔数][帧ID][长度]
  ↓ 验证魔数
_recv_exact(N)   → [FFT数据]
  ↓ 解析float32
np.frombuffer()  → ndarray(10240,)
  ↓ 封装
fft_data_queue.put({data, timestamp, frame_id})
  ↓
DataProcessor
```

---

## 5. 线程安全

- **接收线程**: 独立线程，不阻塞主线程
- **队列保护**: `queue.Queue`内置线程安全
- **状态更新**: 通过`state.communication_thread`触发PyQt信号

---

## 6. 错误处理

| 错误情况 | 处理方式 |
|---------|---------|
| 魔数不匹配 | `_fast_sync()`重新同步 |
| 连接断开 | 返回`None`，退出接收循环 |
| 队列满 | 丢弃最旧数据（FIFO） |
| Socket超时 | 继续等待（无限重试） |

## 9. 性能特性

- **接收速度**: ~100帧/秒 (10240点×4B×100fps ≈ 4MB/s)
- **Socket缓冲**: 1MB (减少丢包)
- **队列大小**: 由`queue.Queue`动态管理
- **内存占用**: ~40KB/帧 (10240×4B)
