# 无人机频谱检测系统 - 系统架构设计文档

## 1. 系统概述

基于射频频谱分析和深度学习的实时无人机检测平台。系统接收20通道扫描FFT数据（覆盖2GHz带宽），实现智能扫描、目标锁定和实时YOLO检测。

### 核心特性

- **宽带扫描**：20通道×512点FFT，总带宽2GHz
- **智能追踪**：扫描-锁定状态机，自动跟踪飞控信号
- **实时检测**：YOLOv8识别，支持OpenVINO GPU加速
- **灵活显示**：扫描窗口/固定频段可切换

### 技术栈

| 层次 | 技术 |
|------|------|
| 通信层 | Socket TCP，单帧协议 |
| 数据处理 | NumPy, OpenCV, 双线程归一化 |
| 算法层 | YOLOv8, OpenVINO, 扫描控制器 |
| 状态管理 | PyQt6 Signal/Slot, JSON配置 |
| UI层 | PyQt6, QtCharts, 主题管理器 |

## 3. 核心模块

### 3.1 通信层 (communication.py)

**职责**：接收20通道扫描FFT数据

**协议**（单帧格式）：
```
[魔数4B][帧ID4B][长度4B][FFT数据 float32×10240]
- 魔数: 0xAABBCCDD
- 数据: 20通道 × 512点 = 10240个float32
```

**核心方法**：
- `connect(ip, port)`: 建立TCP连接
- `send_command(cmd, value)`: 发送控制命令
- `_receive_loop()`: 接收线程，解析帧数据

**关键特性**：
- 精确接收`_recv_exact(n)`确保完整帧
- 魔数同步`_fast_sync()`处理丢包
- 队列满时自动丢弃旧数据

---

### 3.2 数据处理层 (data_process.py)

**职责**：FFT数据→可视化图像

**核心参数**：
```python
channel_count = 20                    # 固定20通道
fft_length = 512                      # 单通道FFT点数
total_fft_length = 10240              # 总频点数
total_bandwidth_mhz = 2000            # 总带宽
```

**双线程设计**：

1. **处理线程** (`_process_loop`):
   ```python
   批量获取FFT → 全局归一化 → 更新waterfall_buffer
   ```
   - 避免亮度跳变（全局min/max）
   - deque循环缓冲（固定高度）

2. **转换线程** (`_image_conversion_loop`):
   ```python
   waterfall_buffer → 归一化[0,1] → OpenCV色图 → RGB图像
   ```
   - 使用`cv2.COLORMAP_JET`
   - 输出BGR格式（width×height×3）

**关键接口**：
- `get_window_image(start_pt, end_pt)`: 获取指定频点范围切片
- `get_point_to_frequency(pt)`: FFT点→频率(MHz)转换
- `set_noise_filter_parameters()`: 噪声滤波配置

**噪声滤波**（可选）：
- **减法模式**：动态噪声底估计+非对称更新
- **阈值模式**：硬阈值抑制

### 3.3 算法层 (algorithms.py + scanning_controller.py)

#### 3.3.1 DroneDetector

**职责**：YOLO检测+扫描控制集成

**模型加载**（优先级）：
1. OpenVINO GPU (`best_openvino_model/`)
2. PyTorch CPU (`best.pt`)

**检测循环**：
```python

    detections = yolo.predict(image)
    scanning_controller.update_state_machine(detections, width)
    annotated = draw_detections(image, detections)
```

**类别**：
```python
0: Noise
1: WiFi
2: Bluetooth
3: Video-transmission signal
4: Flight-control signal (飞控信号 - 锁定目标)
5: Fast-hopping
6: Flight-control pattern
```

#### 3.3.2 ScanningController

**职责**：频率扫描+目标锁定状态机

**状态机**：
```
┌─────────────┐  检测到飞控信号   ┌─────────────┐
│  SCANNING   ├──────────────────►│   LOCKED    │
│ (固定步长)   │                   │ (动态跟踪)   │
└─────────────┘◄──────────────────┴─────────────┘
                信号丢失N帧
```

**SCANNING模式**：
- 固定步长滑动窗口
- 窗口大小 = `scan_bandwidth_mhz`对应的FFT点数
- 步长 = `window_size × (1 - overlap_ratio)`

**LOCKED模式**：
- 锁定飞控信号中心频率
- 平滑跟踪（`tracking_smoothing=0.3`避免抖动）
- 连续`control_lost_threshold`帧无信号→返回SCANNING

**核心方法**：
```python
get_current_window_image() → (image, start_pt, end_pt)
update_state_machine(detections, image_width)
get_status() → 状态信息dict
```

**关键参数**：
- `scan_bandwidth_mhz`: 单窗口带宽（如200MHz）
- `overlap_ratio`: 重叠率（0.5 = 50%）
- `control_lost_threshold`: 丢失阈值（帧数）

## 4. 关键技术点

### 4.1 扫描窗口计算

```python
# 单窗口FFT点数
window_size = scan_bandwidth_mhz / 100 * fft_length

# 窗口步长（考虑重叠）
window_step = window_size * (1 - overlap_ratio)

# 总窗口数
total_windows = (10240 - window_size) // window_step + 1
```

### 4.2 频率-FFT点转换

```python
# 点 → 频率(MHz)
freq_mhz = point_index * 2000 / 10240

# 频率 → 点
point_index = int(freq_mhz * 10240 / 2000)
```

### 4.3 全局归一化（避免亮度跳变）

```python
# 对整个瀑布图buffer统一归一化
waterfall_array = np.array(waterfall_buffer)
min_db, max_db = np.min(waterfall_array), np.max(waterfall_array)
normalized = (waterfall_array - min_db) / (max_db - min_db + 1e-12)
```

### 4.4 OpenVINO加速

```python
# 优先GPU推理
if "GPU" in core.available_devices:
    model = YOLO("best_openvino_model/")
    results = model(image, device="intel:gpu", imgsz=512)

    model = YOLO("best.pt")  # 回退CPU
```

## 7. 性能优化

### 7.1 数据处理优化
- **批量处理**：一次性获取队列所有数据（减少锁竞争）
- **全局归一化**：避免逐帧归一化导致亮度闪烁
- **双线程分离**：图像转换不阻塞数据处理

### 7.2 检测优化
- **OpenVINO GPU**：比PyTorch CPU快3-5倍
- **图像尺寸**：512×512（OpenVINO），640×640（PyTorch）
- **模型预热**：启动时执行dummy推理

### 7.3 UI优化
- **定时器刷新**：固定帧率（30fps）
- **QImage复用**：减少内存分配
- **异步更新**：UI线程仅负责渲染

## 附录B：术语表

- **FFT点**: 频域采样点，10240点覆盖2GHz
- **扫描窗口**: 检测算法的观测频段，可滑动
- **锁定**: 跟踪特定信号的中心频率
- **重叠率**: 相邻窗口的重复区域占比
- **魔数**: 包起始标识符（0xAABBCCDD）

- **重叠率**: 相邻窗口的重复区域占比
- **魔数**: 包起始标识符（0xAABBCCDD）
